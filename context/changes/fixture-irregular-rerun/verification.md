## Why this run exists

Two reasons, and the second was discovered while setting this one up.

**1. The registered confound.** The archived irregular arm read 2/20, but its
fixture contained a REAL compile error — `queue-drain.ts` declared
`const batchDefaults` 16 times — emitted by the generator. Two hand-read
controls correctly reported it as a true defect. That arm therefore could not
separate:

- **H-naming**: removing the enumerable filename sequence removed the
  invented-path fabrication mode; from
- **H-bugs**: the model had genuine bugs to report and spent findings on them
  instead of inventing.

**2. The archived irregular arm's freeze was VIOLATED (found 2026-08-24).**
Its `verification.md` pinned `fixture-irregular.md` at
`f423d87f…`, but its graded file records the grader actually read
`b6bddc46…`. Cause: the file was generated by scripted text replacement, and
the **pre-commit prettier hook reformatted it after the hash was taken**. By
that pre-registration's own rule ("a graded file recording any other hash is
INVALID and enters no denominator"), **the archived 2/20 is formally invalid**.

Verified NOT to affect the other arms — pinned equals grader-read for both:

| Arm               | pinned      | grader-read |     |
| ----------------- | ----------- | ----------- | --- |
| fixture base      | `122bc3ea…` | `122bc3ea…` | ✅  |
| arm A (ordered)   | `1edca060…` | `1edca060…` | ✅  |
| arm B (irregular) | `f423d87f…` | `b6bddc46…` | ❌  |

The reformatting was whitespace/table-alignment only (content verified
identical via `git diff --ignore-all-space`), so the substance was probably
sound — but "probably sound" is not what the freeze discipline is for. This
run re-establishes the number under a correct freeze.

**Mitigation applied here:** the ground truth was run through prettier BEFORE
hashing, and the hash verified stable across a second prettier pass, so the
pinned value is what the commit hook leaves on disk and what the grader will
read.

Primary metric: `fabricationRuns` out of 20. Two comparators, both using the
campaign's band arithmetic:

| Result                      | Condition                                                         | Reading                                                                                                                    |

| **H-bugs was load-bearing** | count ≥ 8 (UNCHANGED vs the base fixture's 11, i.e. \|c−11\| ≤ 3) | Fabrication returns once the model has no true bugs to report → the archived 2/20 was an artifact of the confound          |

M3-dominant → REPRESENTATIVE. On the evidence so far this is not expected.
